# Archive: v1 (3 lb heavy-lift) documents

These are the original Project 006-D drafts for the 3 lb, 650 mm, Pixhawk 6C + Raspberry Pi 4 design, kept for reference.

**They are superseded by the v2 (0.5 lb) design in [`../BUILD_GUIDE.md`](../BUILD_GUIDE.md).** The code samples in these files have known problems that v2 fixes. For example, the grid script arms but never takes off, every script uses the same UDP port, and the camera code doesn't work on current Raspberry Pi OS. Section 11 of the build guide lists every change.
